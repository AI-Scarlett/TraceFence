# Downloads

This folder is a placeholder for download-related metadata.

Actual installers should be published as GitHub Releases rather than committed directly into the repository.

Current macOS release assets:

- `TraceFence-<version>-arm64.dmg`
- `TraceFence-<version>-arm64.dmg.sha256`
- `tracefence-update.json`

The iPhone companion is distributed through [TestFlight](https://testflight.apple.com/join/yZTXmaJ8).

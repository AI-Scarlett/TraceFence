Frequently asked questions

常见问题

  • Where do I download TraceFence? Use GitHub Releases.TraceFence 去哪下载？使用 GitHub Releases。
  • Is there an iPhone client? Yes. TraceFence Sentinel is available through TestFlight.有 iPhone 客户端吗？有，TraceFence Sentinel 已通过 TestFlight 开放。
  • Does agent traffic use a TraceFence relay? No. Use LAN, Tailscale, VPN, or a tunnel you operate.Agent 流量经过 TraceFence 中转吗？不经过，请使用局域网、Tailscale、VPN 或你自己的隧道。
  • Are all agents equally controllable? No. TraceFence only shows actions exposed by the selected adapter.所有 Agent 的控制能力都一样吗？不一样，TraceFence 只显示所选 adapter 提供的操作。

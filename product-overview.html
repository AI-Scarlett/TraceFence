●Product page产品页面

Control supported Mac agents from iPhone without a TraceFence cloud relay.

用 iPhone 控制支持的 Mac Agent，不经过 TraceFence 云中转。

Approve requests, launch or resume sessions, interrupt unsafe runs, and review local agent context over a network you operate.

通过你自己的网络审批请求、启动或继续会话、中断危险运行，并查看本地 Agent 上下文。

Core focus核心方向

  • iPhone approvals and agent session controlsiPhone 审批与 Agent 会话控制
  • multi-agent session and activity visibility多 Agent 会话与活动可视化
  • TokenScope usage and local audit historyTokenScope 用量与本地审计历史
  • LAN, Tailscale, VPN, or a user-operated tunnel局域网、Tailscale、VPN 或用户自有隧道

Product principles产品原则

  • Keep agent data local by default.Agent 数据默认保留在本机。
  • Only show controls that an adapter can execute.只显示 adapter 真正可以执行的控制。
  • Make approvals understandable before a user acts.在用户操作前把审批信息讲清楚。
  • Let users own their remote-access network.让用户掌控自己的远程访问网络。

●TraceFence Sentinel supportTraceFence Sentinel 支持中心

Pair once, then manage your Mac agents securely.

完成一次配对，安全管理 Mac 上的 Agent。

TraceFence Sentinel requires a user-owned Mac running TraceFence Agent Core. There is no TraceFence cloud relay or web account.

TraceFence Sentinel 需要用户本人拥有的 Mac，并运行 TraceFence Agent Core。产品不使用 TraceFence 云端中转，也不需要 Web 账号。

Open a support request提交支持请求 Privacy policy隐私政策

Pair your Mac配对 Mac

  1. Open TraceFence on the Mac and select the iPhone connection icon.在 Mac 打开 TraceFence，点击左下角的 iPhone 连接图标。
  2. Keep the pairing panel open and scan its QR code in Sentinel.保持配对弹窗打开，在 Sentinel 中扫描二维码。
  3. Approve Face ID, Touch ID, or device passcode authentication.通过面容 ID、触控 ID 或设备密码认证。

Connect outside your Wi-Fi通过互联网连接

Install Tailscale or another VPN on both devices and join the same private network. TraceFence will remember previously paired routes and retry them automatically. A sleeping, powered-off, or offline Mac cannot accept commands.

在 Mac 和 iPhone 上安装 Tailscale 或其他 VPN，并加入同一个私有网络。TraceFence 会保存历史配对通道并自动重试。处于睡眠、关机或断网状态的 Mac 无法接收控制指令。

Sessions or projects are missing看不到会话或项目

  • Confirm Agent Core shows Online in Sentinel Settings.确认 Sentinel 设置中的 Agent Core 显示在线。
  • Update Agent Core from the Mac before reinstalling either app.先在 Mac 更新 Agent Core，不必立即重装两端 App。
  • Only installed agents and recent displayable sessions appear.界面只展示已安装 Agent 和符合时间范围的有效会话。

Notifications and language通知与语言

Enable notifications from Sentinel Settings. The iOS permission sheet is rendered by the operating system and follows the device language; all in-app notification controls follow the language selected in Sentinel.

请从 Sentinel 设置中主动开启通知。iOS 系统授权框由操作系统绘制并跟随设备语言；App 内的通知设置和说明会跟随 Sentinel 选择的语言。

What to include in a support request提交支持请求时请附上

Include the iOS build number, macOS TraceFence version, Agent Core version, affected agent name, connection type (local Wi-Fi or VPN), and a screenshot with tokens or private prompts hidden. Never post a pairing token publicly.

请提供 iOS 构建号、macOS TraceFence 版本、Agent Core 版本、受影响的 Agent 名称、连接方式（局域网或 VPN）以及已遮盖令牌和私密提示词的截图。请勿公开发布配对令牌。

Support is provided through the public TraceFence issue tracker.技术支持通过 TraceFence 公开 Issue 跟踪器提供。
